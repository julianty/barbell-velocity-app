## Proposed module layout (pending user confirmation)

```
lib/analysis/            pure Dart, zero flutter/platform imports
  analysis_config.dart   AnalysisConfig — all tunables, reference defaults
  signal.dart            interpolate, removeOutliers, savgolFilter, computeVelocity
  pelt.dart              PELT l2 (min_size=2, jump=5 — ruptures-compatible)
  find_peaks.dart        scipy-compatible distance+prominence peak finding
  concentric.dart        detectConcentricRuptures / detectConcentricPeaks + Segment
  rep_metrics.dart       phases + velocity + fps → List<RepResult>
  pipeline.dart          BarbellTrack → AnalysisResult (composes the above)
  models.dart            BarbellTrack, TrackPoint, Segment, RepResult, AnalysisResult
lib/input/               FrameSource iface + web/ios impls, file picking
lib/inference/           InferenceBackend iface, onnx_web + ultralytics_ios impls,
                         track_builder.dart (port of build_barbell_track.py)
lib/ui/                  results screen, velocity chart, progress states
test/analysis/           unit tests per module
test/fixtures/           golden JSONs from Python reference
test/golden/             regression tests vs fixtures
```
